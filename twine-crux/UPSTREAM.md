# Twine in Crux Garden

Actual Twine 2.12.0 from https://github.com/klembot/twinejs, tag 2.12.0, commit 020b8dcd308d0103bb8ca1f547f2eaae247f17e8. Native source, passage map/editor, story formats, CSS/script editing and HTML publishing remain. Twine is GPL-3.0; its license and native story-format notices travel with the source/runtime. Third-party dependency notices are collected from build maps.

Garden loads the saved library before mounting Twine. Native localStorage is isolated memory; each story, passage, preference and story-format record is saved as a fingerprinted JSON Artifact referenced by data/project.json. An edit therefore does not duplicate the full story library. Story passage editing is debounced upstream; Garden reports the draft immediately and waits for its native persistence callback before closing or checkpointing. Undo stacks, open dialogs and story playthrough state are transient.

The native browser-storage quota display and browser-only onboarding warning are omitted because Garden owns persistence. Built-in formats are local. User-added remote formats and external media URLs remain external dependencies and are not automatically copied into the Crux; do not claim an offline story if its author references remote resources. Native HTML export is distinct from Export complete Crux, which includes the private editable library and history. Whole-editor website publication is unavailable.

Native Play/Test/Proof use the native publishing engine inside an isolated preview overlay, with a Return to story editor button. Story scripts run in a sandbox without access to the editor's origin. Agent tools inspect story IDs and bounded passage previews, rename an existing story, and replace one existing passage through the native reducer. New links create destination passages through Twine's normal behavior. Passage inspection returns the first 100 passages per story with 2,000-character text previews and truncation flags; passage replacement accepts up to 100,000 characters. Agent edits do not play or execute story scripts.

Rebuild with Node 22: npm ci --ignore-scripts && npm run build. The upstream Electron packaging and PWA installation are not used. Source and pinned dependencies rebuild runtime; npm run check, npm run test:garden and npm run test:native cover TypeScript, the persistence model, Electron host detection, pending passage drafts and export timing. Host registration and real desktop writing, linking, Play, HTML/Twee exports, agent title/passage edits, conflict recovery, restart and complete archive import into a fresh profile are covered by electron/e2e/twine-app.spec.ts. See the root BUILD-LOG for verification evidence and remaining collection-wide work.
