# Ketcher in Crux Garden

Native Ketcher 3.13.0 Editor, core and standalone provider, using the upstream npm distributions from https://github.com/epam/ketcher. The Indigo 1.41.0 chemistry engine is bundled locally. This preserves the actual molecular editor UI and native structure/reaction editing, rather than a replacement drawing app. Ketcher and Indigo retain their upstream Apache-2.0 licensing; dependency notices accompany the runtime.

Garden waits for its saved project before starting the editor. Native KET and the native settings/custom-template library are separate fingerprinted JSON Artifacts. localStorage is isolated memory hydrated from those Artifacts; supported keys are ketcher_editor_saved_settings, ketcher-opts and ketcher-tmpls. Browser caches, native undo and clipboard contents are not portable state. Images embedded inside native KET currently remain inside that structure Artifact; changing the structure may therefore store another copy of its inline images. Molecule/reaction editing is the current scope; macromolecule mode is disabled.

Native open/save and chemical format exports remain. Initial scoped agent operations inspect the structure and replace it through the native setMolecule API. Chemistry service operations are tracked so Garden's close/save boundary waits for pending work. Project JSON and immutable assets remain in the owning Working Copy and Growth. Complete editor website publication is unavailable.

Rebuild with Node 22: npm ci && npm run build. The exact upstream packages and Indigo version are locked; their native interface is mounted by main.jsx. Vite supports their mixed ESM/CommonJS dependency format and maps global to globalThis. Generated maps are used for dependency notices and excluded from the portable runtime. App verify passed 933 host tests plus embedded gates; Electron verify passed. The real desktop journey verifies manual drawing, native custom-template save and reopening, scoped agent ethanol editing, KET/MOL/PNG exports, native file reimport, external-file conflict/reload, restart and complete archive import into a fresh profile with the original Project Folder unavailable. The imported drawing remains editable. Screenshots are in app/docs/ketcher. Created-Crux source rebuild status is recorded in the root BUILD-LOG. Molecule mode is exercised; macromolecules remain disabled.
