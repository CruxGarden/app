How to earn points

5 XP for each criterion with a result and evidence. 15 bonus XP for a fully recorded mission. 100 bonus XP and a badge for charting every mission in a stage. Pass, fail, blocked and justified exclusions earn the same investigation points.

Editing or repeating a result never farms points. Correcting/removing evidence recalculates the score. Levels come every 250 XP. XP measures investigation, not release readiness.

Your rehearsal setup and the rules for a pass

Use one continuing example if that helps: Mosslight Studio, with a personal home page, a notebook, a drawing and a small interactive order form. Substitute your own interest. The point is to achieve the outcome, not reproduce someone else’s files.

  • Protect your real work. Use disposable test data and a second isolated installation for import/recovery. Test installation and updates on a clean OS account or spare device. The provided manual-testing launcher opens the existing testing Garden; it is not a fresh-install test. Do not wipe it to start this guide.
  • Bring a small kit: photo, Markdown text, CSV, PDF, short audio/video, two test identities, an external editor and a directory for exports. Add provider keys, catalog access, signing artifacts or a test domain only for the stories that need them.
  • Try the goal before the hints. If you need hidden knowledge to continue, record that as a usability issue even if the feature technically works.
  • Pass means a demonstrated outcome. Open the saved file, editable native project or real public URL. “The agent said done,” a success toast and an old automated result are not substitutes.
  • Blocked means a missing prerequisite. Not applicable requires a release-scope reason. A promised feature that is unavailable is blocked or failed, not silently excluded.
  • Mark both the story and its detailed criteria. A passed story with untested criteria remains incomplete in the ledger. Record build, OS, provider and hosted/local target; do not reuse one OS/provider result for another.
  • Results stay in this browser under this guide’s own storage key; they do not modify Garden or the older checklist. Export before clearing browser data, changing machines or starting a new run. Do not put keys or private account data in notes.
