Limits: conversion bakes only pixels within the current canvas and replaces source editing data (native Undo or a prior duplicate retains it). Selected merges require adjacent visible source-over layers without an adjacent clipping dependency. Visible merge uses the native complete composite and retains hidden/empty layers in their order, but revealing them later cannot restore their former interleaving with removed layers. The raster target preserves the original opacity/composition/visibility; complete merges bake these into normal composition at 100% opacity. No extra native renderer/merge module fork; one narrow insertion repair, isolated Garden helpers and existing native actions. The existing preparation revision guard is not inspection-to-edit freshness or a guarantee for overlapping gestures. Existing Project Folders need explicit source/runtime refresh to receive these operations.
