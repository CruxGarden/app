# miniPaint shared-edit preservation

Status: verified scripted desktop preservation journey, 2026-09-15. Nineteen App Tools remain. This adds comparison guards, not more creative operations.

The scripted agent uses normal Collaboration tools while the person uses the actual native editor. `electron/e2e/minipaint-freshness.spec.ts` checks stale/missing inspection tokens, manual opacity committed from a focused field, Undo/Redo returning identical artwork, zoom-only continuation, refusal during a held brush gesture, completed native brush points, and an image fetch overlapping a manual edit. The import must refuse without adding the layer; inspection and retry must preserve the person's edit. Local fixture-file arrival is allowed to reload the preview before testing the import race.

`calls.json` and `shared-edits.png` are generated by that journey. The final journey passed in 35.9 seconds with 19 calls, including five intentional refusals and successful recovery. Manual opacity and brush points persisted; a stale import added no layer, and retry preserved opacity. No captured page errors. These scripted checks do not establish real-model usefulness, native typography quality, full gesture coverage or large-document performance. Existing Cruxes need an explicit source/runtime refresh.

An earlier run exposed a Garden adapter timing bug: its observer deferred native action invocation through a Promise callback, while native brush startup immediately reads the inserted layer. The corrected adapter calls the action synchronously and observes its returned Promise. No brush-source patch is needed. The test retains a real native stroke and rejects page errors so this failure stays covered.
