# One Big Sky in Crux Garden

Game by **Downcast Systems**: https://github.com/downcastsystems/onebigsky

Imported at commit **ab06154ed46059ecab7ce247d172310e37da3744** on 2026-09-10 at the user's request. Game logic, art, synthesized audio and presentation remain upstream's. Formatting may follow Garden's tooling. Upstream does not supply a repository-wide license; this integration does not assign one. Silkscreen's font license is retained in `assets/fonts/OFL.txt`.

Garden supplies a starting point in Add Crux and preserves the game's editable sources as Artifacts. The bundled development copy retains upstream tests and its localhost launcher. Created Cruxes contain the directly runnable HTML, JavaScript, CSS, fonts and guides; they omit the optional Node launcher and package manifest so no build server or package installation is needed.

The One Big Sky Mood is separate Garden artwork and styling. It does not alter this game's sprites, physics or screens.
