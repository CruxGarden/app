# Resume

A Crux Garden template: a one-page resume built on Astro, seeded from
[astro-resume](https://github.com/EmaSuriano/astro-resume) (MIT) by
[Ema Suriano](https://github.com/EmaSuriano).

**The whole resume is one Markdown file: `src/pages/index.md`.** Headings make
the sections, and the layout does the rest. There is no data format to learn.

- **Print or save as PDF**: the button at the top-right prints the page; the
  print styles are what make it come out as one clean page.
- **Light and dark**: the toggle beside it, remembered per visitor.
- **Preview**: the Workshop runs `astro dev`; `pnpm dev` works in a terminal too.
- **Share**: `astro build` renders `dist/`, which Crux Garden publishes.

See `UPSTREAM.md` for what is upstream's and what Crux Garden changed.
