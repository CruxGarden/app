# SVG-Edit in Crux Garden

Actual SVG-Edit 7.4.2, tag v7.4.2, commit e2ab43cfa9ed27bf268d8484eacf35cc25e3681c, from https://github.com/SVG-Edit/svgedit. The native editor, SVG canvas, layers, paths, text, styles, local shape extensions and native SVG/raster export engines remain. Upstream source and license files are included; retain its composite package license declaration and component notices. Production/workspace dependency notices accompany the runtime, including dependencies hidden behind the prebuilt canvas workspace.

The Garden bridge loads before the native editor. Local storage is per-frame memory; the browser-storage extension is disabled. Drawing SVG, supported editor preferences and each embedded image are separate fingerprinted JSON Artifacts referenced by data/project.json. Image data URLs are replaced with private component tokens only in the saved drawing; hydration resolves them before native parsing. Unchanged image content is reused across vector edits. This format is private editable state, not an exported SVG. Native exports retain real image data. External image/font URLs remain external and are not silently downloaded.

The native source dialog must be applied or closed before Garden checkpoints or closes the editor, so an uncommitted source draft is not discarded. Pointer operations finish before capture. Undo stacks, open dialogs, viewport positions and clipboard contents are transient. Preferences are restored from an allowlist of native preferences and selected display/grid settings; saved data cannot select extensions or load code by URL.

Agent tools inspect up to 200 shape IDs, set the document title, or change one existing shape's fill with native undoable editing. Native image exports download the editor's rendered output inside Garden instead of opening a separate window. Native SVG opening/importing/saving remains available. Whole-editor website publication is unavailable; exported SVG/PNG artwork can be used in another project.

Node 22: npm ci --ignore-scripts && npm run build. The build includes the native canvas and editor, local extensions and their assets; extension dependency paths are renamed to vendor so no node_modules directory is required in the Crux runtime. npm run test:native runs upstream unit tests; npm run test:garden checks the persistence model. The real desktop journey electron/e2e/svgedit-app.spec.ts covers manual drawing, imported image reuse, agent styling, native SVG/PNG, external conflict/reload, restart and complete archive import into a fresh profile with the original folder unavailable. Consult the root integration plan and BUILD-LOG for final verification evidence and collection-wide work.
