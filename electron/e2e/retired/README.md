# Retired journeys

These specs were written for the pre-unification chrome (modal Settings and
Console, a relaunch that reopened the last Crux, Growth snapshots on every AI
turn, the old sync archive format). They are excluded from the run
(`testIgnore` in `playwright.config.ts`) and kept only as a list of what they
covered. A small new journey set replaces them; when one of these covers
something the new set does not, port the intent, not the selectors.
