# Glow Garden demo art

Generated by `make-art.py` (no image library): a 4-frame gardener walk sheet (128×32, 32×32 frames), a glowing seed (32×32) and an 800×600 garden ground. Authored for Crux Garden's Glow Garden demo Cruxspace; released CC0. The journey imports them into Piskel Cruxes through Piskel's own import wizard, so the sprites genuinely live in those Cruxes before they are shared.
