## My site preview will not start

Read the error shown by the build or preview. First-time Astro setup needs dependencies from the internet. Check your connection, the site’s package file, and available disk space. A syntax error in one page can prevent the site from building.

Do not delete your Project Folder to fix a preview problem. Export important work before experimenting with files.

## I cannot publish

Confirm that you are connected to your account and that the site builds locally. Read the Share error and retry only after addressing it. A local preview does not establish that the hosted API, email delivery, domain, or storage is available.

If Share fails, do not assume an older public version has been removed.

## An agent is waiting or progress stopped

Open the Task and check its latest message, approval request, and provider error. An estimated progress bar can pause while the agent waits for a tool. Check the configured provider and remaining usage before retrying.

Avoid launching multiple copies of the same assignment while the original may still be running.

## Changes appear in the wrong place

Check the active Crux, selected Task, and Project Folder path. Close a historical Growth view before editing the current version. An exported folder is a copy; changing it does not necessarily edit the original Crux.

## Report a useful issue

Include your app version, operating system, the smallest steps that reproduce the problem, and what you expected. Remove API keys, access tokens, personal content, and email addresses from logs or screenshots before sharing them.

A small reproduction helps far more than an entire private Garden.
