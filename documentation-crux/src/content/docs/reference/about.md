## Read anywhere

The app bundles a built copy of this Starlight site. Open it from **Explore → Field guide** without signing in, enabling AI, or downloading dependencies. Its search index is bundled too.

The public docs use the same Markdown, components, and styles. The local copy reflects the app version you installed; the website may be newer.

## Make it yours

Choose **Make a copy** from the local guide to create an ordinary Site Crux. Its pages appear in the Builder, and its source appears in Artifacts. You can edit, keep versions in Growth, export privately, and publish using Share.

Copying does not require AI. The first editable Astro preview or build needs its dependencies and may require the internet. The bundled reading copy stays available while you work.

Updates replace the app’s bundled guide, never the files in your personal copy. New copies receive the version shipped with the current app.

## Made with Starlight

[Starlight](https://starlight.astro.build/) supplies accessible documentation navigation, search, color themes, and readable page layouts. Crux Garden adds its own content, typography, colors, and journal. Upstream licenses and provenance travel with the editable Crux.
