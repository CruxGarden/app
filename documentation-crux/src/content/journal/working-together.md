Parallel work is most useful when the pieces are easy to understand. One task drafts the introduction. Another checks the navigation. Each has a clear place to work and a result you can review.

## Small requests, useful feedback

Tell an agent what a good result looks like. Ask for progress that describes what it has learned, what is waiting, and what remains. A number alone cannot tell the whole story.

When work returns, read it. Preview it. Ask whether it makes the creation better. Completion is a useful signal; your judgment still matters.

## Learn by playing

Crux Garden: The Zen of Vibecoding starts with one task and gradually adds more moving parts. It is a place to experiment with how work travels between tasks, how the interface reports back, and how the whole process feels.

The goal is a creative practice that is understandable, playful, and yours.
