# Crux Garden field guide

An ordinary Astro + Starlight Site Crux. Read locally, edit your own copy, or publish it.

Use the Builder for page content and settings, or edit Markdown under src/content/docs.
Journal stories live under src/content/journal. The first editable preview needs Node 22.12+
and installed dependencies: npm ci, then npm run dev. npm run build produces dist.

The app's bundled reading copy needs no AI, network, or dependency installation.
Publishing requires account access and network connectivity. Keep private archives separately.

Built with [Starlight](https://starlight.astro.build/). See UPSTREAM.md and LICENSE.
