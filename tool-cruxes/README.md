# V1 tool sampler

Dependency bootstrap for four planned local tools: OpenMosh effects, Tables (Tabulator), smplr, and PlayCanvas Engine. Versions and install integrity are pinned in package-lock.json.

This checkpoint contains dependencies only. The app adapters, interfaces, shared save session and verification journeys are in progress; these tools are not yet available in Add Crux. No website publication or full PlayCanvas Editor integration is implied.
