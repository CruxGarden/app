# GDevelop native web editor — Garden adaptation

This folder retains the native GDevelop web editor with Garden persistence. Native scene/object/event editors remain intact. The real Garden desktop journey has exercised sprite and behavior editing, keyboard movement, agent changes, both native exports, conflict/reload, restart, and complete Crux import into a fresh profile with the original Project Folder unavailable. Further editing and preview passed there. The app-created source setup/build also passed. Editable ZIP reimport with original assets, independently booting the exported game and creating a native 3D Box after fresh-profile import also passed. The complete desktop journey passed in 3.0 minutes. Screenshots are in app/docs/gdevelop in the Garden repository.

Node 22: `npm run setup` installs the pinned editor/runtime dependencies with lifecycle scripts disabled, applies upstream patches and builds. Later `npm run build` reuses dependencies. The complete source layout is retained because native build scripts consume Core/Extensions/GDJS/GDevelop.js and newIDE siblings. The native engine uses exact-commit JS/WASM downloads with SHA-256 validation; no floating branch fallback is used. Their corresponding source and native build instructions are in GDevelop.js/README.md. The native import script needs NODE_PATH pointed at editor dependencies when copying these prebuilt files.

The engine SHA-256 pins are in garden/build.cjs. Upstream source tarball SHA-256: fb8b734cb88123c3d954fde15d7e8a59b285aecb635f4170cdc5430eb00b2692. The Lingui Git dependency is locked to dc6b1e013470d952cf85f96cc4affdd28e29634a by the upstream lockfile.

Garden replaces native project storage with confirmed saves to data/project.json and separate fingerprinted document, media and preference Artifacts. Browser IndexedDB is generated preview storage; original imported bytes are retained in the Crux. A few scoped agent tools inspect the game, rename it and change a scene background. Editable project ZIP and native web-game ZIP are distinct from a complete private Crux archive. Assets are limited to 32 MiB per file; archive imports to 128 MiB. Self-contained resources are the supported import path; external resource dependencies are not automatically collected.

Garden hides upstream hosted accounts, cloud builds, asset-store suggestions and its separate AI controls. Unused hosted data providers, remote analytics loading and preview screenshot uploads are disabled. Optional Spine runtime packages and registrations are excluded; Spine projects are rejected explicitly. No upstream hosted service, account or asset-store entitlement is supplied. Whole-editor website publication is unavailable. The source and app names remain credited to their upstream authors; this independent adaptation does not imply endorsement.

The native build writes runtime/THIRD_PARTY_NOTICES.txt and runtime/bundled-packages.json. These inventory bundled editor dependencies; a full public distribution audit, including completeness of upstream package notices and separately copied runtime libraries, remains open. GDevelop’s top-level MIT license is not a claim that all dependencies use MIT.
